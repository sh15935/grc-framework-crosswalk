# GRC Framework Crosswalk

Educational mapping between cybersecurity frameworks and regulations, to help students and consultants see how one control satisfies several requirements.

## Covered
- NIS2 Directive (EU 2022/2555), Article 21(2)
- ISO/IEC 27001:2022 (clauses and Annex A)
- ANSSI IT hygiene guide
- NIST CSF 2.0
- Morocco: Loi 05-20, DNSSI, Law 09-08 *(planned)*
